## Chat and media behavior

One composer serves both general business interaction and selected-work direction. Context is visible and clearable. Add media supplies a possible source/reference; it does not mean replace, render or publish automatically. Voice is an optional modality, not compulsory. In this specimen the voice button inserts a labeled transcript without opening a microphone.

Store a real request's caller, work version, paused moment or interval, normalized selected region/source transform, instruction, scope and admitted media references. The sample circle stores normalized points against a fictional version/moment in tab memory only. The prototype does not implement real duration selection, frame extraction, timestamp verification, backend persistence or model comprehension.

Questions should explain, not mutate. Explicit actions remain subject to their normal identity, budget, creative-contract and confirmation rules. One-off correction, durable preference, protected identity and publishing authority are different. The prototype uses a trivial question-mark fixture to demonstrate different receipts; it is expressly NOT the production intent-classification algorithm. Every receipt says no effect was applied.

## Asset understanding hidden behind the simple surface

The customer does not tag footage. The intended backend identifies relevant usable spans and describes observations, possible uses, limitations and rights. Retrieval is driven by the selected creative block's function and constraints, not visual similarity alone. A reference mechanism does not provide rights or factual proof. Analysis permission, rendering permission and public distribution permission are distinct.

No semantic analysis is performed on local uploads here. The 20 MB intake limit and accepted file types are specimen choices only, not approved production limits. Object URLs are local previews and are revoked on removal/unload; no remote upload occurs. No real identity, account connection, payment or publication is performed. This focused specimen omits secure sign-in, checkout, actual entitlement, final publication, permission recovery and other existing flows; navigating between specimen screens does not authorize bypassing them in production.
